# The Nirea guide

This guide teaches Nirea by example, one topic per page. It assumes you know a language such as Java or C. Every complete example compiles and runs, and its comments show what it prints.

- [1. Getting started](01-getting-started.md): build the compiler and run a first program.
- [2. Basics](02-basics.md): variables, initialisation, numbers, functions, control flow, switch and constants.
- [3. Strings](03-strings.md): the `String` type and its methods.
- [4. Arrays](04-arrays.md): Java-style arrays.
- [5. Structs and interfaces](05-structs.md): fields, methods, constructors, `private`, equality and interfaces.
- [6. Enums](06-enums.md): named values and exhaustive switches.
- [7. Ownership](07-ownership.md): owners, transfers, copies and value parameters.
- [8. References](08-references.md): working on an object in place, many readers, and returning references.
- [9. Global objects](09-global-objects.md): objects that belong to the whole program.
- [10. Namespaces and projects](10-projects.md): namespaces, imports and the project layout.
- [11. Calling C](11-c-interop.md): `extern "C"` functions and C libraries.
- [12. Windows](12-windows.md): building and using the compiler on Windows.

The [specification](../spec/README.md) gives the exact rules for every topic.
